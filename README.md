# Portfolio Pessoal - Lucas Lustosa

Acesse o portfolio online: https://thelustosa.github.io/portfolio/

Este repositorio contem o codigo-fonte do meu portfolio pessoal web. A aplicacao foi desenvolvida para apresentar meus projetos, trajetoria profissional, competencias tecnicas e informacoes de contato de maneira clara, responsiva e interativa.

## Funcionalidades Principais

- Suporte Multilingue: Internacionalizacao dinamica com suporte a Portugues e Ingles via JavaScript.
- Tema Claro e Escuro: Alternancia de tema visual adaptavel a preferencia do usuario.
- Filtragem de Projetos: Visualizacao de projetos categorizados por tags (AI, DASHBOARD, WEB, GAME).
- Linha do Tempo Profissional: Apresentacao cronologica da trajetoria de estudos e experiencia profissional.
- Design Responsivo: Interface otimizada para navegacao em dispositivos moveis, tablets e computadores.

## Tecnologias Utilizadas

- HTML5: Estrutura semantica e acessivel.
- CSS3: Estilizacao moderna com CSS Variables, Flexbox, Grid e animacoes.
- JavaScript (ES6+): Logica de interatividade, controle de tema e internacionalizacao.

## Estrutura do Projeto

```text
lustosa-dev-main/
├── index.html        # Estrutura principal da pagina
├── style.css         # Estilos, variaveis de tema e responsividade
├── script.js         # Logica de traducao, temas, filtros e dinamismo
├── assets/           # Imagens e arquivos estaticos
├── favicon.svg       # Icones do site
└── README.md         # Documentacao do projeto
```

## Como Executar Localmente

1. Clone este repositorio:
   ```bash
   git clone https://github.com/thelustosa/portfolio.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd portfolio
   ```

3. Abra o arquivo `index.html` em seu navegador de preferencia ou utilize a extensao Live Server do seu editor de codigo.
